# Capital Shop — Fashion E-Commerce Website

Capital Shop is a responsive fashion e-commerce website developed as part of a Front-End Development course project.

The project focuses on building a modern, visually appealing shopping interface using **HTML5 and CSS3**, with an emphasis on layout, styling, and responsive design.

## Live Demo

[View Live Website](https://muhammadmansour844-web.github.io/Project2_Course_Front/)

## Features

- Responsive fashion store layout
- Navigation bar with shopping categories
- Promotional hero section
- Trending products section
- Product cards with prices and discounts
- Customer testimonials
- Recommended products section
- Fashion news and blog section
- Newsletter subscription interface
- Footer with navigation and store information
- CSS hover effects and visual transitions

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## Project Structure

The project contains HTML files, CSS stylesheets, images, and font assets used to build the website.

## Project Purpose

This project was created to practice:

- Writing semantic HTML
- Designing reusable page sections
- Working with CSS layouts and positioning
- Creating responsive designs
- Applying typography, spacing, and color consistency
- Improving front-end development skills

## Current Limitations

This is a front-end design project built without JavaScript.

Some buttons, product links, and shopping-related elements are included for visual presentation only and do not provide full e-commerce functionality.

Interactive features such as shopping carts, product filtering, and dynamic navigation may be implemented in future projects.
